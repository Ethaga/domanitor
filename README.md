# Domanitor

**Domanitor** is a web-based demo platform for **domain tokenization** on the **Doma Protocol**, built as a submission to the **DomainFi Hackathon**.  
It is currently available in **demo (testnet) mode** — no real funds are required.

---

## 🚀 How to Use

Access the live demo on Netlify: `https://xxxxxxxxxxm.netlify.app/`

1. Open the site to view the **Domanitor landing page**.
2. Click **Connect Wallet** and connect your crypto wallet (MetaMask, WalletConnect, etc.).  
   Make sure you are connected to the **testnet**.
3. Once your wallet is active:
   - Statistics such as *Total Domains*, *Market Cap*, etc. will update in real time.
   - Navigate through the demo features:
     - **AI Valuation Demo** → Predict domain prices automatically.  
     - **Trademark Shield Demo** → Test anti-squatting protection.  
     - **Enterprise Tools Demo** → Manage brand assets across platforms.
   - Explore the menu: **Tokenize** domains individually or in bulk (Bulk Tokenize), **Fractionalize**, access **Portfolio**, **Marketplace**, **Bridge**, **Monitoring**, **Analytics**, and **Alerts**.
4. All interactions are performed on **testnet**, so no real money is required.

## ✨ Key Features

### 🔑 Decentralized Identity (DID)
Decentralized and encrypted authorization of domain ownership.

### 🔗 Connect Wallet
Connect your crypto wallet (MetaMask, WalletConnect, etc.) to start interacting with testnet features.

### 📊 Real-time Statistics
Automatically updated metrics:
- Total Domains  
- Tokenized Value  
- Market Cap  
- 24h Transactions  
- Unique Users  
- Revenue Potential  

### 💡 Domanitor Advantages
- **AI Valuation Engine** → Domain price prediction powered by machine learning.  
- **Trademark Shield** → Automatic anti-squatting protection.  
- **Enterprise Tools** → Cross-domain brand management for `.com` & `.web3`.  

### 🧭 Navigation & Features
- **Portfolio** → Real-time monitoring of tokenized domains, supporting `.eth`, `.sol`, `.bnb`, and more.  
- **Tokenize / Bulk Tokenize** → Tokenize single domains or multiple at once.  
- **Fractionalize** → Split ownership of domain tokens.  
- **Marketplace** → Explore tokenized domains.  
- **Bridge, Monitoring, Analytics, Alerts** → Tools for management and insights.
