# Domanitor
**Domanitor** is a web-based demo platform for **domain tokenization** on the Doma Protocol, built as a submission to the **DomainFi Hackathon**. It is currently available in **demo (testnet)** mode — no real funds are required.

##  Cara Penggunaan

Akses demo langsung di Netlify: `https://xxxxxxxxxxm.netlify.app/

1. **Buka situs** untuk melihat halaman utama Domanitor.
2. Klik **Connect Wallet** dan lakukan koneksi dengan wallet crypto Anda (pastikan terhubung ke testnet).
3. Setelah wallet aktif:
   - Data statistik (Total Domains, Market Cap, dll.) akan diperbarui secara real-time.
   - Navigasikan fitur seperti:
     - **AI Valuation Demo** → prediksi harga domain secara otomatis.  
     - **Trademark Shield Demo** → uji proteksi anti-squatting.  
     - **Enterprise Tools Demo** → manajemen brand lintas platform.
   - Eksplorasi menu: Tokenize domain satu-per-satu atau secara massal (Bulk Tokenize), fractionalize, akses Portfolio, Marketplace, Bridge, Monitoring, Analytics, Alerts.
4. Semua interaksi dilakukan di **testnet**, sehingga tidak membutuhkan uang asli.


##  Fitur Utama
**Decentralized Identity (DID)**  
  Otorisasi kepemilikan domain secara terdesentralisasi dan terenkripsi.

- **Connect Wallet**  
  Hubungkan dompet crypto (MetaMask, WalletConnect, dll.) untuk mulai berinteraksi dengan fitur testnet.

- Tampilan statistik otomatis:  
  Total Domains, Tokenized Value, Market Cap, 24h Transactions, Unique Users, Revenue Potential.

- **Kelebihan Domanitor**:  
  - *AI Valuation Engine*: Prediksi harga domain berbasis machine learning.  
  - *Trademark Shield*: Proteksi anti-squatting otomatis.  
  - *Enterprise Tools*: Manajemen brand lintas domain .com & .web3.

**Menu Navigasi & Fitur**:  
  Portfolio, Tokenize, Marketplace, Bridge, Monitoring, Analytics, Alerts.  
  - *Portfolio*: Monitoring real-time portofolio domain tokenized Anda, mendukung .eth, .sol, .bnb dan lainnya.  
  - *Bulk Tokenize*, *Market Analysis*, dan *Fractionalize*: Mempermudah tokenisasi massal, analisis pasar, dan pembagian kepemilikan domain.
